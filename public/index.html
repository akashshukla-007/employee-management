Import from Excel

Upload a workbook in the same layout. Employee data is matched and updated by Employee ID, and any embedded Photo/Signature images are extracted and attached to the correct employee automatically.

Large files with many embedded photos can exceed the ~3MB upload limit imposed by the hosting platform. If import fails on a very large workbook, split it into smaller batches (e.g. by site code) and import each one separately.
